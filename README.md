# 🏛️ TRA NEXUS - Ecosystem System

TRA NEXUS ni mfumo wa kidigitali wa usimamizi wa kodi, ugunduzi wa fursa za soko, na utoaji wa elimu ya kodi kwa mlipakodi.

---

## 🚀 Teknolojia Zilizotumika (Tech Stack)
* **Backend:** Python 3 (Flask)
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Production Server:** Gunicorn (WSGI)
* **Deployment:** Render
